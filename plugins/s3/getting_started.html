S3

Getting Started

  1. Create an IAM user with permission to use S3, or get temporary credentials from a Cognito identity pool.
  2. Call Create Aws S3 Object with the credentials, a Client Configuration with the Region of your bucket, and a Payload Signing Policy. See Initializing the Plugin.
  3. Store the S3 Client Object from the callback in a variable.
  4. Pass it to the S3 nodes, for example List Buckets or Get Object. See Using the Plugin.

When you are done, call Destroy S3 Object.

Payload Signing Policy​

ValueDescription
Request DependentEach request decides if its body is signed. Use this if you are unsure.
AlwaysAlways sign the body. Safest, but uploads are slower because the whole file is hashed first.
NeverNever sign the body. Faster uploads over HTTPS.

Region​

Use the region of the bucket. If you don't know it, Get Bucket Location returns it.

tip

Limit the IAM policy to the buckets and actions the game needs, for example s3:GetObject on arn:aws:s3:::my-game-content/*.
