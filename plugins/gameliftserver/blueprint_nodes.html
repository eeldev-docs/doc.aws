GameLift Server

Blueprint Nodes

All nodes are in the AWS > GameLift > Server category. Most of them call the Server SDK action with the same name.

Return values​

The nodes run right away and return true on success. On failure they return false and set:

OutputDescription
Error TypeThe Server SDK error, for example GAMELIFT_SERVER_NOT_INITIALIZED or PROCESS_NOT_ACTIVE.
Error MessageThe error message from the Server SDK.

GameLift Server Object​

Create a Blueprint with this class as the parent. See Using the Plugin.

Functions​

NodeDescription
Init SdkInitializes the Server SDK with the Server Parameters and calls ProcessReady.
Destroy GameLift ServerCalls Process Ending, shuts down the Server SDK and stops sending events to the Server Object.
Activate Game SessionTells GameLift the server is ready for players. Call it from Start Game Session if you override it.
Process EndingTells GameLift the server process is shutting down.
Get Game Session IdThe id of the game session on this server, if one is active.
Get Termination TimeWhen GameLift will shut down the server process, in epoch seconds, or -1 if no shutdown is scheduled. Use it in Process Terminate.
Accept Player SessionValidates a player session id when a player connects.
Remove Player SessionTells GameLift a player has left.
Describe Player SessionsGets player sessions by player session id, game session id or player id. Use Limit and Next Token to page through the results.
Update Player Session Creation PolicyACCEPT_ALL or DENY_ALL new player sessions for the game session.
Start Match BackfillAsks FlexMatch to find players for open slots. Returns the backfill Ticket Id. The result comes to Update Game Session.
Stop Match BackfillCancels a backfill request.
Get Compute CertificateThe path to the TLS certificate and the compute name. Needs a fleet with certificate generation turned on.
Get Fleet Role CredentialsTemporary AWS credentials for the fleet's IAM role: access key id, secret access key, session token and expiration. Use them to call other AWS services from the server.

Events​

EventDescription
Start Game SessionGameLift placed a game session on this server.
Update Game SessionMatchmaker data was updated by a backfill, or a backfill failed.
Process TerminateGameLift is shutting down the server process.
Server Health CheckReturn false if the server is unhealthy.

See Server events for what they do by default.

Properties​

PropertyDescription
Server ParametersWeb Socket Url, Fleet Id, Process Id, Host Id, Auth Token, Aws Region, Access Key, Secret Key and Session Token. Leave empty on managed EC2 fleets.
Log File PathThe folder of the log file GameLift uploads when the game session ends.
Log File NameThe name of the log file.

GameLift Server Game Mode​

See Game Mode.

NodeDescription
Validate Player LoginOverride to reject a player with an error message.
PreLoginOverride to read the connect options.
Get Player Session IdThe player session id of a Player Controller.

Types​

TypeDescription
Server Game SessionGame session id, name, fleet id, maximum player session count, status, game properties, IP address, DNS name, port, game session data and matchmaker data.
Server Update Game SessionThe updated game session and the Update Reason: MATCHMAKING_DATA_UPDATED, BACKFILL_FAILED, BACKFILL_TIMED_OUT or BACKFILL_CANCELLED.
Server Player SessionPlayer session id, player id, game session id, fleet id, creation and termination time, status, IP address, DNS name, port and player data.
Start Match Backfill Request ServerTicket id, matchmaking configuration ARN, game session ARN and the current players with their attributes and latencies.
