GameLift Server

The GameLift Server plugin runs on your dedicated server and connects it to Amazon GameLift. It reports to GameLift when the server is ready, receives game sessions, answers health checks and shuts the server down when GameLift asks it to.

The plugin is built on the Amazon GameLift Server SDK 5.3.0.

Features​

  • Initialize the server on a managed EC2 fleet or a GameLift Anywhere fleet. See Using the Plugin and GameLift Anywhere.
  • Server events that you override in Blueprint: Start Game Session, Update Game Session, Process Terminate and Server Health Check.
  • Player session validation in the included GameLift Server Game Mode, which accepts and removes player sessions for you. See Game Mode.
  • FlexMatch backfill with Start Match Backfill and Stop Match Backfill.
  • Player sessions: Accept Player Session, Remove Player Session, Describe Player Sessions and Update Player Session Creation Policy.
  • Fleet IAM role credentials with Get Fleet Role Credentials, so the server can call other AWS services without stored keys.
  • Compute certificate with Get Compute Certificate, for TLS on fleets with certificate generation turned on.
  • All nodes have the same names as the Server SDK actions in the AWS documentation.

Server plugin or Client plugin?​

PluginRuns onUsed for
GameLift ServerThe dedicated serverTalking to GameLift from the server process: ready, game sessions, health checks, player sessions, backfill.
GameLift ClientA backend, tool or game clientThe GameLift service API: creating game sessions and player sessions, matchmaking, fleets, builds, Anywhere computes.

You only need the Server plugin if something else creates your game sessions, for example your own backend or the AWS console.

You need both plugins for GameLift Anywhere when the server registers itself, because only the Client plugin can register a compute and get an auth token.

Requirements​

Target platformsWindows and Linux. On Mac, Android and iOS the plugin builds, but the GameLift calls do nothing.
BuildA dedicated server target. See the Unreal Engine documentation on how to build one.
Server SDKAmazon GameLift Server SDK 5.3.0, included in the plugin
Unreal EngineSee the Fab listing for the supported engine versions
