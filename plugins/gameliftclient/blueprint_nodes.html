GameLift Client

Blueprint Nodes

Every GameLift action is an async node in the AWS > GameLift category, with the same name as in the GameLift API Reference. Each node takes the Game Lift Object and a Request, and calls Callback with Success, Result, Error Type and Error Message. See Getting Started.

Client object and utilities​

NodeDescription
Create Game Lift ObjectCreates the client object with credentials and a client configuration. Calls the callback when it is ready.
Destroy Game Lift ObjectFrees the client object.
Construct Player IdCreates a random player id.
Get Player IdThe player id created by Construct Player Id.
Get Log File Path NameThe path, file name and extension of the game's log file.
Get Game Port From WorldThe port of the world's URL.
AWS UUIDCreates a random UUID.

Game sessions​

Node
Create Game SessionStarts a new game session on a fleet.
Describe Game SessionsGets game sessions by id, fleet or alias.
Describe Game Session DetailsGets game sessions with their protection policy.
Search Game SessionsFinds game sessions with a filter and sort expression.
Update Game SessionChanges the name, maximum players, creation policy or protection.
Get Game Session Log UrlThe URL of the log file uploaded by the server.
Start Game Session PlacementPlaces a new game session through a queue.
Describe Game Session PlacementGets the status of a placement.
Stop Game Session PlacementCancels a placement.

Player sessions​

Node
Create Player SessionReserves a slot for one player in a game session.
Create Player SessionsReserves slots for several players.
Describe Player SessionsGets player sessions by id, game session or player.

Error types​

Error Type is one of the AWS errors below, or UNKNOWN.

Error TypeMeaning
ACCESS_DENIED, UNAUTHORIZEDThe IAM user doesn't have permission for the action.
INVALID_CLIENT_TOKEN_ID, INVALID_ACCESS_KEY_ID, SIGNATURE_DOES_NOT_MATCHWrong access key or secret key.
REQUEST_TIME_TOO_SKEWEDThe computer's clock is wrong.
NETWORK_CONNECTION, REQUEST_TIMEOUTGameLift could not be reached.
THROTTLING, SLOW_DOWNToo many requests. Wait and try again.
INVALID_REQUEST, INVALID_PARAMETER_VALUE, MISSING_PARAMETER, VALIDATIONA field in the request is wrong or missing.
NOT_FOUND, RESOURCE_NOT_FOUNDThe fleet, game session or other resource doesn't exist.
CONFLICTThe resource is in a state that doesn't allow the action.
FLEET_CAPACITY_EXCEEDEDNo server process is free to host a new game session.
GAME_SESSION_FULLThe game session has no free player slots.
INVALID_FLEET_STATUS, INVALID_GAME_SESSION_STATUSThe fleet or game session isn't active.
LIMIT_EXCEEDEDAn AWS service limit was reached.
NOT_READYThe resource isn't ready yet.
TERMINAL_ROUTING_STRATEGYThe alias has a terminal routing strategy.
UNSUPPORTED_REGIONGameLift isn't available in the region.
IDEMPOTENT_PARAMETER_MISMATCHAn idempotency token or id was reused with different values.
INTERNAL_FAILURE, INTERNAL_SERVICE, SERVICE_UNAVAILABLEA problem on the AWS side. Try again.
