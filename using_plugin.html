Using the Plugin

All AWS actions are async nodes. Pass the client object and a Request, and use the Callback pin. The node calls it when AWS has answered, with:

OutputDescription
SuccessTrue if the call succeeded.
ResultThe response from AWS.
Error TypeThe AWS error, for example ACCESS_DENIED or RESOURCE_NOT_FOUND.
Error MessageThe error message from AWS.

Follow the AWS documentation​

The nodes, requests and fields have the same names as in the AWS API documentation. You find the link to the API documentation of each plugin in the sidebar, under the plugin.

Common errors​

Error TypeWhat to check
ACCESS_DENIED, UNAUTHORIZEDThe IAM user doesn't have permission for the action. Add it to the user's policy.
INVALID_CLIENT_TOKEN_ID, SIGNATURE_DOES_NOT_MATCHThe access key or secret key is wrong, or the session token is missing for temporary credentials.
REQUEST_TIME_TOO_SKEWEDThe computer's clock is wrong.
RESOURCE_NOT_FOUNDThe resource doesn't exist, or it is in another region than the client object.
NETWORK_CONNECTIONAWS could not be reached.

To see what the plugin does, turn on verbose logging. See the Logging page of the plugin.
