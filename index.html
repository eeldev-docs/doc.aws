AWS Plugins for Unreal Engine

The eelDev AWS plugins let you use Amazon Web Services from Blueprint and C++ in Unreal Engine. Each plugin is sold separately and contains its own copy of the AWS SDK, so you only add the services you need.

PluginUsed for
CognitoSign-up, sign-in and user management with user pools, and temporary AWS credentials with identity pools.
DynamoDBReading and writing items in a NoSQL database.
GameLift ClientThe GameLift service API: game sessions, player sessions, matchmaking, fleets.
GameLift ServerRunning your dedicated server on GameLift.
LambdaCalling your own serverless functions.
PollyTurning text into speech that you can play in the game.
S3Uploading and downloading files.
STSTemporary credentials and assuming IAM roles.

How the plugins work​

All plugins work the same way:

  1. Create an IAM user with permission to use the service.
  2. Install the plugin in your project.
  3. Create the client object with your credentials and region.
  4. Call the nodes. They have the same names as the actions in the AWS API documentation.
